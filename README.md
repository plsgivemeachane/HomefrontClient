# HomefrontClient

Homefront PvP client for Minecraft 1.8.9, built on a fully decompiled MCP (Mod Coder Pack) workspace.

## Getting started

When you open this using Eclipse with the workspace path set to `./eclipse/`, it'll be ready to work with.

On Linux, `./startclient-linux.sh` compiles and launches the client (needs a Java 8 JDK).

The Minecraft jars, libraries and assets (`jars/`) are not included in this repository. Copy them into `jars/` from a Minecraft 1.8.9 install before building.

If you have questions about the MCP base, ask here: https://discord.gg/yaftWcn
